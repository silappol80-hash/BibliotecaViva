## Objetivo do Software
O **BibliotecaViva** é um sistema desktop desenvolvido para automatizar e simplificar o controlo de rotinas de uma biblioteca, permitindo o gerenciamento integrado de utilizadores e o registo de livros com respetivos preços e vínculos relacionais.

## Funcionalidades do Sistema (Requisitos)
* **Cadastro de Utilizadores:** Registo de novos leitores com validação de dados únicos (nome, e-mail).
* **Cadastro de Livros:** Registo de obras literárias informando título, autor, preço e o utilizador responsável pelo registo.
* **Persistência de Dados:** Integração completa com base de dados relacional MySQL via padrão DAO (Data Access Object).
